# Tetris Hub

Веб-платформа для сообщества игроков в Тетрис.

## 🚀 Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Язык | TypeScript 5.7+ |
| Frontend | React 19 + Next.js 16 (App Router) |
| Стилизация | Tailwind CSS 3.4 |
| Backend | tRPC 11 + Node.js |
| Auth | Better-Auth 1.6 |
| БД | SQLite 3.53 + Drizzle ORM 0.45 |
| Тесты | Vitest 2.1 + Testing Library |

## 📦 Установка

```bash
# Установить зависимости
npm install --legacy-peer-deps

# Настроить переменные окружения
cp .env.example .env

# Применить схему БД
npm run db:push

# Запустить в режиме разработки
npm run dev
```

## 🧪 Тестирование

```bash
npm run test          # Все тесты
npm run test:watch    # Watch-режим
npm run typecheck     # Проверка типов
```

## 🗄️ Работа с базой данных

```bash
npm run db:generate   # Сгенерировать миграции
npm run db:push       # Применить миграции
npm run db:studio     # Запустить Drizzle Studio
```

## 🔐 Аутентификация

Платформа использует Better-Auth с поддержкой:
- Регистрации и входа по email/паролю
- Сессий на основе JWT
- Защиты маршрутов через middleware

- Поиск и фильтрация

- Темы с вложенными ответами

- Лайки и комментарии

### 🏆 Достижения
- Автоматическая выдача за активность
- Прогресс выполнения
- Коллекция в профиле
